Introduction to Computer Systems

A fundamental 1.0 credit laboratory course covering internal computer mechanisms, memory vs. storage, algorithmic problem solving using flowcharts, Code.org logic, Beecrowd problem solving, and C programming.

Course Outcomes (COs) & Program Outcomes (POs)

Verbatim UGC approved learning targets and accreditation mapping for CSE 1110

CO1 Bloom's: C

Identify the components of a computer and demonstrate its internal mechanisms.

Evaluated in: Assignment, Midterm
CO2 Bloom's: C

Derive the solution steps and flowchart of any programs.

Evaluated in: Assignment, Midterm
CO3 Bloom's: C

Analyze the code to find errors and trace outputs manually.

Evaluated in: Final Exam, Viva
CO4 Bloom's: C

Use a programming language to write error-free programs.

Evaluated in: Final Exam, Viva
